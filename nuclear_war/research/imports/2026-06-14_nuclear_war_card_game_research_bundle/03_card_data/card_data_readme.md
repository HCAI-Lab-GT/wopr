# Card data README

The card CSVs are intended for simulation modeling, not exact reproduction.

Columns to add during physical-card transcription:

- `edition_in_hand`
- `card_back_or_deck_identifier`
- `exact_front_text`
- `capacity_or_megatonnage`
- `population_delta`
- `timing_window`
- `targeting_rule`
- `defense_interactions`
- `image_filename_private_only`
- `transcriber`
- `verified_by_second_pass`

Do not distribute exact text/art publicly unless licensed. For internal simulation, map exact cards to effect functions and keep provenance fields.
