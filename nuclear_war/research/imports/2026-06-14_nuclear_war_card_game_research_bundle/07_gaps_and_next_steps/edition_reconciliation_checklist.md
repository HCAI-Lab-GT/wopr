# Edition reconciliation checklist

Use this when comparing the user's physical copy against online sources.

## Components

- [ ] Rule sheet or rulebook page count.
- [ ] Spinner present?
- [ ] Dice present?
- [ ] Number of population cards.
- [ ] Population denomination counts.
- [ ] Number of Nuclear War cards.
- [ ] Strategy mats/player mats count.
- [ ] Deck back/color identifiers.
- [ ] Publisher logo/printing date.
- [ ] Artist/credit line.

## Rule differences

- [ ] Initial player selection: owner vs random player.
- [ ] Starting population by player count.
- [ ] Initial hand size.
- [ ] Draw-to size during turn.
- [ ] Whether scheduled cards count toward hand size.
- [ ] Number of face-down strategy cards.
- [ ] Anti-missile timing.
- [ ] Anti-missile turn-order jump.
- [ ] Bomber persistence and payload rules.
- [ ] War/peace reset rules.
- [ ] Final retaliation timing and eligible cards.
- [ ] Everyone-loses/global chain-reaction rule.

## Card manifest

- [ ] Common warhead/propaganda counts match source inventory.
- [ ] Base delivery systems match source inventory.
- [ ] Anti-missile names/counts match source inventory.
- [ ] Secrets/top secrets match source inventory.
- [ ] Promo/booster/later-added cards identified.
- [ ] Non-play ads/jokers separated.
